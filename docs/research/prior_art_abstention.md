## 2. Re-test of prior claims

**(1) "Calibrated delay is nearly empty as a research area."** False as of 2026-11. 2026 alone has dedicated benchmarks (AgentAbstain, arXiv preprint; Agentic Abstention, NeurIPS 2026; SteerBench-Work; SentryBench), a framework paper (Designing for Doubt, AIES 2026), and conformal act/abstain gates for agents (CORA, Conformal Selective Acting, Role-Stratified CRC, ToolChain-CRC), building on KnowNo (2023) and UALA (2024). What is still thin is the *combination*: none of these evaluates a calibrated gate on an irreversible decision against strategic adversaries with known hidden ground truth.
Replacement: "Confidence-gated abstention for agent actions became an active area in 2026 (e.g., AgentAbstain, arXiv:2607.10059; SteerBench-Work, arXiv:2608.12654; CORA, arXiv:2604.09155), but these benchmarks use non-adversarial or injection-only settings; we found no study of calibrated delay for an irreversible group decision under strategic deception."

**(2) "Exformation: 1 paper."** Not reproducible. The arXiv API full-text-metadata search for `exformation` (2026-11-12) returns 3 hits, all false matches on "EXFormer"/transformer stemming; none uses the term. Web and arXiv-restricted searches found no LLM/AI paper using "exformation". The term originates with Nørretranders (The User Illusion, 1991 Danish / 1998 English). Semantic Scholar was rate-limited, so non-arXiv venues are not exhaustively checked. The *concept* is studied under other names: deception by omission (arXiv:2610.11351), omission-aware misinformation detection (arXiv:2512.01728), "omission" as a deception category in WOLF (arXiv:2512.09187), and underspecification (arXiv:2505.13360).
Replacement: "We found no arXiv or indexed AI paper that uses the term 'exformation' (searched 2026-11-12); the closest work studies omission as deception (arXiv:2610.11351, arXiv:2512.09187) or underspecified prompts, without using omissions as evidence for an action gate."

**(3) "Jev: 0 papers."** False. At least eight arXiv preprints from Sept-Oct 2026 study TypeSafe's Jev: 2609.29429 (RLCD / RLCDAlignBench, apparently from the model's developers), 2609.37647 (independent benchmark, 37 datasets), 2609.33401 (System One models for agent security decisions, incl. selective automation), 2609.35342 (Sys1Cal-v1, missing "unknown" mass), 2609.26532 (REFLEX routing), 2609.24052 (crash narratives), 2610.19811 (risk-budgeted decisions), 2610.18773 (Jeva). Model launched in early access around 2026-09-15 (secondary source). Note the requester's model id is `typesafe/jev-1.14`; papers report 1.13 or unspecified versions.
Replacement: "Jev, a 'System One' calibrated-decision model released in September 2026, already has a small preprint literature on calibration and gating (e.g., arXiv:2609.29429, 2609.33401, 2609.35342), including use as an agent security gate; none tests it as a delay gate on an irreversible decision in an adversarial multi-agent game."

## 3. Metric conventions worth adopting

| Convention | Definition for our study | Used by |
|---|---|---|
| Act/abstain confusion matrix | 2x2 over {should-act, should-abstain} x {acted, delayed}: act-correct (lynch Mafia), act-harmful (lynch villager), abstain-justified (no-lynch when evidence insufficient / would have hit villager), abstain-needless (no-lynch when a correct lynch was available). Need an operational "should-abstain" label fixed in pre-reg (e.g., Bayesian posterior over roles from engine log below a threshold). | AgentAbstain (paired act/abstain accuracy); Wen et al. survey (2x2 answerable/unanswerable); Designing for Doubt (SR/UR) |
| Paired accuracy / constant-policy cap | Report that always-act and always-delay each score <=50% paired; doubles as a null floor | AgentAbstain |
| False-hold rate (over-caution) | P(delay \| correct lynch available) | SteerBench-Work ("wrongly hold", 28.1%); Designing for Doubt (1 - Usability Rate); SentryBench (over-refusal) |
| False-proceed rate | P(lynch \| should delay) or P(lynch villager) | SteerBench-Work ("wrongly allow"); Designing for Doubt (1 - Safety Rate); SentryBench (attack success / over-reaction) |
| Post-hoc abstention | Agent votes then states it would have delayed; our say-do gap at the action boundary | AgentAbstain |
| Timeliness | Days until correct lynch; delays that later convert to correct action vs wasted days | Agentic Abstention (timely recall rate) |
| Risk-coverage curve, AURC / E-AURC | Sweep gate threshold tau; coverage = fraction of days the gate acts; risk = villager-lynch rate among acted days. State orientation (lower-is-better error AURC). | RLSR (2607.03528), Phillips et al. (2603.21172), BAS (2604.03216); not used by Rabanser et al. |
| ECE, Brier, AUROC | Calibration of gate confidence vs lynch-correctness; report per game day (trajectory checkpoints), not only pooled | Rabanser et al. (2602.16666), WOLF (Brier), TC-ECE (2609.07395), Jev papers |
| Asymmetric harm cost | Weighted cost: c_harm x villager-lynch + c_delay x needless delay; reports whether caution is harm-dominated | SentryBench |
| Selective automation under a miss limit | Fraction auto-acted given max allowed harmful-act rate | 2609.33401 (System One security), CORA (risk budget) |
| Subgroup calibration | ECE by scenario type (e.g., Mafia bus-throw, quiet Mafia), since pooled ECE hides confident errors | 2609.33401 |
| Run-to-run consistency | Same seed, K repeats | Rabanser et al.; AgentAbstain lists single-run as a limitation |
| Explicit-tag extraction for say vs do | Parse stated decision from a tagged field, not free text | 2606.00476 (22-26% vs <2% artefact) |
